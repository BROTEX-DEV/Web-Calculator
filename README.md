# Web Calculator

یک ماشین حساب وب ساده و مدرن با HTML، CSS و JavaScript.

## امکانات

- عملیات جمع، تفریق، ضرب و تقسیم
- درصد
- تغییر علامت عدد
- پاک کردن ورودی و کل محاسبات
- حذف آخرین رقم
- پشتیبانی از کیبورد
- طراحی واکنش گرا برای موبایل و دسکتاپ
- بدون نیاز به کتابخانه خارجی

## اجرا

فایل `index.html` را در مرورگر باز کنید.

## تکنولوژی

- HTML
- CSS
- JavaScript
